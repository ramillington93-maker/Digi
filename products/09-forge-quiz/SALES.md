## Title
ForgeQuiz — a static lead-magnet quiz funnel, no backend

## Subtitle
Turn 7 questions into an email list. No server, no code, ready in 15 minutes.

## Pitch (~120 words)

ForgeQuiz is a 7-question quiz that scores each visitor into one of 3
results and hands them a downloadable summary with their email on it.
It's pure HTML, CSS, and JavaScript — no backend, no database, no
monthly hosting bill. Double-click `index.html` and it runs, or drop
the folder on any static host.

The default niche is "Which digital product should you sell this
week?" — swap the questions, options, and results for your own niche
in `QUIZ-COPY.md`, then paste the new copy into `index.html`. Every
question, option, and result is documented in plain text so you don't
need to read code to edit it.

Ship a lead magnet today. Connect a real email list when you're ready
— instructions included.

## 5 bullets

- 7 questions, 3 results, fully scored client-side — no backend to host or pay for.
- Downloadable result file (Blob-based, works offline) gives visitors something real on submit.
- Every piece of copy documented in `QUIZ-COPY.md` — swap the niche without touching code.
- Mobile-first, works down to 375px, dark theme, Google Fonts (Inter + JetBrains Mono).
- Opens by double-clicking `index.html`. No npm, no build step, no config.

## FAQ

**Do I need to know how to code?** No for basic use — open the file
and click through. Editing the copy means opening a text file and
changing text between quotes; `QUIZ-COPY.md` shows you exactly what to
change.

**Does it collect real emails?** Not out of the box — it downloads a
result file to the visitor's device. `README.md` shows how to wire it
to ConvertKit, Mailchimp, or any provider with an HTML embed form.

**Can I resell this template?** No. You can sell what you build with
it (your quiz, your niche, your funnel). See `LICENSE.txt`.

**Does it work on phones?** Yes, tested down to 375px width.

**Do I need hosting?** No — it opens directly from a folder. Upload it
to any static host if you want a public URL.
