# DEMO.md — 20-second demo recording steps

Goal: show the whole loop — type product, pick platform/tone, generate, scroll the result — in about 20 seconds.

1. Open a terminal in this folder and run `streamlit run app.py`. Let it fully load in your browser before you start recording.
2. Start your screen recorder (window capture on the browser tab is enough, no need for full screen).
3. Clear the product description field if anything is in it.
4. Type: `a 30-day fitness planner PDF for busy parents` (about 2 seconds — type it at normal speed, don't rush).
5. Click the **Platform** dropdown, select **Instagram**. (1 second)
6. Click the **Tone** dropdown, select **bold**. (1 second)
7. Click **Generate**. (Generation is near-instant — no loading wait to cut.)
8. Scroll slowly down through the results for about 8 seconds: captions first, then hooks, then hashtags, then CTAs, then the first comment. Don't pause on any one section.
9. Stop recording once the first-comment section is visible on screen.
10. Trim the clip to start right as you begin typing and end right after the first-comment line appears — that's your 20 seconds.

No editing needed beyond the trim. Don't show the terminal or the `streamlit run` command in the final clip — start the recording after the app is already loaded.
