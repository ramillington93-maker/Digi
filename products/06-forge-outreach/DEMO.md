# DEMO.md — recording a 20-second demo

Exact steps to record the ForgeOutreach demo clip. Screen size
1280x720 or larger. No audio needed — captions or silent is fine.

1. Run `streamlit run app.py` and let the browser tab load to
   `localhost:8501` before you start recording.
2. Start screen recording. Frame the full browser window, address bar
   hidden if possible.
3. (0:00–0:03) Show the app title "ForgeOutreach" and the three input
   boxes already filled with the defaults (offer, ICP, proof point).
4. (0:03–0:05) Click into the **Proof point** field and briefly
   highlight the text to show it's editable — no need to retype it.
5. (0:05–0:07) Click the **Generate sequence** button.
6. (0:07–0:14) Scroll down through the 5 generated emails, pausing
   about 1 second on each day badge (DAY 0, DAY 2, DAY 4, DAY 7, DAY
   12) so the viewer sees all 5 distinct angles and both subject
   lines per email.
7. (0:14–0:17) Scroll to the **Export** section. Click **Download .csv
   (Instantly / Lemlist upload)**.
8. (0:17–0:20) Show the downloaded file appear (browser download tray
   or file manager), then end the recording.
9. Trim the clip to 18–20 seconds total. No editing required beyond a
   hard cut at start and end.
10. Export as `.mp4` or `.gif` for the Gumroad listing.
