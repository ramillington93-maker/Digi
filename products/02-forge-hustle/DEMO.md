# DEMO.md — recording the 20-second demo

Goal: show the CSV-to-Notion import working, then show one finished board. No voiceover needed — captions or none are fine.

## Before you record

1. Open a clean Notion workspace (or a throwaway one) — no unrelated pages visible in the sidebar.
2. Have the `/databases` folder open in Finder/Explorer, visible and ready to drag.
3. Set your screen recorder to 1080p or higher, cursor visible.

## Shot list (20 seconds, 5 shots)

1. **0:00–0:04 — The empty page.** Show a blank Notion page titled "ForgeHustle Tracker." Cursor visible, nothing else on screen.
2. **0:04–0:09 — The import.** Drag `Offers.csv` from the file explorer into the Notion page (or use `/csv` → Import CSV). Let the database populate on screen — don't cut away until rows are visible.
3. **0:09–0:13 — Speed through the rest.** Jump-cut (or 4x speed) through importing `Experiments.csv`, `Content.csv`, `Revenue.csv`, and `Prompts.csv`. This can be one fast clip, not five separate real-time imports.
4. **0:13–0:18 — The payoff.** Switch the Offers database to Board view, grouped by Status. Let it sit on screen for a full 4-5 seconds — this is the "wow, it's organized" moment.
5. **0:18–0:20 — End card.** Cut to a static frame: product name "ForgeHustle" + price. Hold for 2 seconds.

## Recording tips

- Record each shot 2-3 times. Import animations can stutter on the first take.
- Keep the cursor moving with intent — don't hover and pause mid-drag.
- If you jump-cut the CSV imports (shot 3), speed up to 3-4x rather than skipping straight to the finished result — buyers want to see it's a real import, not a pre-built template.
- Export at the platform's native aspect ratio: square (1:1) for Gumroad's product thumbnail slot, vertical (9:16) if repurposing for a launch tweet or Reel.
- Trim silence at the very start and end. 20 seconds means 20 seconds of content, not 20 seconds including a 2-second dead intro.

## Where to use the final clip

- Gumroad product page (primary media slot)
- Launch tweet/thread (see `PROMPTS.md`, prompt #5, Launch Tweet Thread)
- Anywhere you'd normally post a static screenshot instead
