# Weekly review template

Do this every Friday. Takes 15 minutes if your databases are up to date, an hour if they're not — which is its own signal.

Copy this checklist into a new page or a Notion callout block at the top of your workspace and fill it in.

## 1. Revenue check

- [ ] Total revenue this week: $______
- [ ] Which offer earned it: ______
- [ ] Compare to last week: up / down / flat
- [ ] Any recurring revenue that's about to renew or churn: ______

## 2. Experiments check

- [ ] How many experiments did I finish this week: ______
- [ ] How many got a real result (Win/Loss/Partial), not "Testing": ______
- [ ] Best result this week and why: ______
- [ ] Worst result this week and why: ______

## 3. Content check

- [ ] How many pieces did I publish this week: ______
- [ ] Which one got the most clicks/replies: ______
- [ ] Did it link back to a live offer, or was it just noise: ______

## 4. Offer check

- [ ] Any offer ready to move status (Idea → Testing, Testing → Validated, anything → Killed): ______
- [ ] Confidence score changes — did anything go up or down: ______
- [ ] Next Monday's one offer to push: ______

## 5. One honest question

Pick one:

- What did I avoid doing this week because it was uncomfortable, not because it was low-priority?
- If I had to 2x revenue next month using only what's already Validated, what's the plan?
- What's the one experiment I keep putting off logging because I know the result is bad?

Write the answer in two sentences. Don't skip this section — it's the only one a spreadsheet can't do for you.
