# Demo recording steps (20 seconds)

Record your screen at 1280x720 or higher. No voiceover needed — captions or
silent with on-screen text both work.

1. **0:00-0:03** — Open `calendar-30-day.csv` in Google Sheets (or Notion, after import). Show the full grid: date, platform, hook, cta, asset_type columns visible.
2. **0:03-0:07** — Scroll down through a few rows slowly so the platform variety (X, Instagram, LinkedIn, TikTok) is visible.
3. **0:07-0:10** — Copy one hook cell, e.g. "I replaced 3 subscriptions with one $20 AI tool. Here's what changed."
4. **0:10-0:15** — Switch to the running hook remixer (`streamlit run app.py`), paste the hook into the text box, click **Remix**.
5. **0:15-0:19** — Show the 5 variants appearing (question, number, contrarian, how I, curiosity-gap forms).
6. **0:19-0:20** — End on the full calendar CSV view or the product title card.

## Notes

- Run `streamlit run app.py` before recording so it's already loaded — don't record the install step.
- No API key needed for this demo. The rule-based mode is the one to show; it's the one every buyer gets by default.
- Keep zoom high enough that hook text is readable at thumbnail size.
